## Protected categories

| Category                              | Behavior                                               | Rationale                                                                    |
| ------------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------- |
| Passwords                             | Never requested or changed                             | No cleanup path and outside product boundary                                 |
| Passkeys/WebAuthn                     | Never requested or changed                             | Credential material is protected                                             |
| Bookmarks                             | Permission absent; never changed                       | Explicit exclusion                                                           |
| Browser Sync/account state            | APIs/storage absent; protected service targets blocked | Prevent account-wide effects                                                 |
| Autofill profiles                     | Never calls profile-wide `formData` removal            | Chrome does not expose a safe site-specific path                             |
| Payment methods                       | Same protected boundary as autofill                    | `formData` can affect payment data                                           |
| Site permission/content-setting rules | Preserved                                              | No safe arbitrary per-target deletion without overriding user/policy choices |

## Standard versus Expert

Standard mode keeps associated domains empty, local targets disabled unless separately configured, protected/PWA origin cleanup off, embedded-frame discovery off, expanded partition/exhaustive/recent/broad discovery off, on-disk deletion off, post-wipe blocking off, and optional tab/OPFS controls off. Switching to Standard, first entering Expert, disabling embedded discovery, or resetting settings persists the feature off and removes optional `webNavigation`; a later explicit Expert gesture is required to enable it.

Detailed review is the default in both modes. It displays Expert associated, local/IP, protected/PWA, preflight-bound file, persistent-shield, permission-requesting, private, and uncertain scope and requires every applicable acknowledgement. The separate, default-off `skipCleanupReview` setting is available in Standard and Expert after an explicit warning. When enabled, entering or selecting a valid target completes the same hidden fresh read-only preflight and durable prompt-pending lease before **Clean now** becomes available. One **Clean now** activation then consumes a setting-derived `settings_direct` record without the detailed screen or typed file phrase, after any additional native normal-window prompt. The preflight binds target/current settings/context/complete impact/access inventory/file IDs, and the message, approval, and authorization boundaries accept only the exact prepared `detailed_review` or `settings_direct` mode. Chrome/Brave may show its own target-access prompt after the final detailed approval or direct action, so one SiteWipe action is not always one total browser interaction. A private-source direct run requires **Allow in incognito** and pre-existing exact target access before preflight.

The detailed in-product matrix is generated from `src/shared/constants.js`; public wording must remain aligned with browser evidence and this document.
