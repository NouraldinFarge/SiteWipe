Hard limitationsWhat no extension can erase

SiteWipe removes only data exposed through Chrome/Brave extension APIs. It cannot erase ISP logs, DNS resolver logs, router logs, VPN provider logs, operating-system logs, antivirus or endpoint-security logs, enterprise monitoring, firewall records, remote website/CDN logs, account activity on a website, payment records, receipts, screenshots, backups, browser sync copies already uploaded elsewhere, data outside Chrome/Brave, memory artifacts, or hidden browser internals. Files on disk are preserved unless the separate irreversible Expert option for preflight-bound completed downloads is enabled; failed or uncertain file removals retain their browser download record for recovery.
