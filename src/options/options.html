Manual setup
  1. Open chrome://extensions or brave://extensions.
  2. Find SiteWipe and choose Details.
  3. Enable Allow in incognito.
  4. Review and run cleanup again. The popup and report will show whether private cleanup access is available.

SiteWipe never claims private cleanup happened unless Chrome/Brave exposes incognito access to the extension.
