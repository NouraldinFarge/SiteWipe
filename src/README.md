# Runtime source

> **Public-source prerelease candidate undergoing safety, privacy, accessibility, and binary-release validation.**

This directory is the unpacked Manifest V3 runtime root. `manifest.json` is intentionally at this level, and the deterministic loadable ZIP maps the allowlisted contents of this directory to the archive root.

`SiteWipe` is the owner-approved custom product identity, and MIT is the owner-approved first-party project license. Known exact-name browser-extension listings mean uniqueness and legal clearance are not claimed. Version `1.12.2` is a public-source prerelease; it must not be represented as a supported binary or submitted to a browser store before its remaining gates pass.

Use the repository-level [`README.md`](../README.md) for architecture, safety boundaries, permissions, validation status, and local-review instructions. The evidence registry and release-readiness ledger under [`docs/`](../docs/) are authoritative for public claims.

Do not load this extension in a daily browser profile. Use a disposable Chrome or Brave profile with synthetic test data. Detailed scope-and-impact review is the default in Standard and Expert. The explicitly confirmed, default-off **Skip detailed cleanup review completely** setting enables `settings_direct` in either mode: SiteWipe completes a hidden fresh preflight and durable permission lease before enabling **Clean now**. With exact access pregranted, one SiteWipe activation submits the ordinary single-use cleanup route. When exact normal-window access is missing, activation one durably arms the reviewed approval, awaits the worker's exact acknowledgement, and opens or focuses one exact worker-created extension-owned handoff tab without requesting access or starting cleanup. Activation two occurs only in that bound document. Its raw single-use capability stays in page memory and never enters the static URL, history, storage, job, report, export, diagnostics, or logs; direct-open, duplicate, reloaded, navigated, replaced, stale, or wrong-context pages cannot continue. Permission possession and events are never cleanup authority. Verify default/direct behavior, truthful reports, the preflight-bound target/settings/private/access/impact/file IDs, exact handoff identity and teardown, and temporary site-access recovery after cancellation, abandonment, denial, failure, worker termination, and restart. Private-source direct runs additionally require browser-controlled **Allow in incognito** and pre-existing exact target access.
